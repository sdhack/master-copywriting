# 四平台中心思想与规则（references/platforms.md）

> **Source of Truth：平台规律。** 平台决定用户消费心智和传播逻辑。主 SKILL.md 只保留 Router 简要调用；本文件是平台规律的唯一 Source of Truth。
> 24 模式中心思想不在此定义，见 `24-modes.md`（Source of Truth：24 模式中心思想）。本文件只描述平台层面的规律与表达倾向。
> 平台功能（粉丝门槛、广告产品、挂载规范）时效性强，投放前必须官方复核，本文件不写死精确数字。

## 平台总览

| 平台 | 一句话本质 | 核心规则（方向性） | 触发词 |
|---|---|---|---|
| **抖音** | 兴趣/内容电商，逛出冲动；争夺注意力 | 前段承担停止划走、识别目标用户和建立继续观看理由的任务，应尽快进入有效信息；脚本=钩子→正文→结尾；垂直原创；直播五类话术（留人/互动/成交/追单/转款） | 抖音/短视频/口播/直播/千川 |
| **小红书** | 社交+内容+电商种草，主动搜攻略；参考价值 | 种草体、利他真实；标题三要素（有用/有趣/共鸣）；埋关键词保收录；封面承担第二标题作用 | 小红书/种草/笔记/图文 |
| **视频号** | 微信生态短内容，社交推荐+私域闭环；信任与社交传播 | 表情熟关系语境、简短亲和；发布后可联动好友/朋友圈/社群；可连公众号/私域 | 视频号/微信短视频/分享话术 |
| **公众号** | 微信长图文/软文，订阅沉淀私域；认知与思想 | 标题显著影响打开意愿，但正文前段留存、内容价值和转发意愿共同影响传播表现；软文给价值非硬广；开头抓人/布局引导/结尾促互动 | 公众号/推文/软文/长图文 |

**平台通用底线**：不产虚假功效、夸大承诺、违禁词（"最/第一/根治"等）；不搬运抄袭；不脱离账号垂直定位。

## 抖音（中心思想：争夺注意力）

用户第一反应不是"我要不要认真研究"，而是"我要不要继续看"。因此优先：**强钩子 → 快速价值 → 持续刺激 → 完播 → 行动。**

- 普通内容：Hook→Value→Proof / 问题→反转→答案 / BAB。重点：信息增量 + 完播推进。
- 普通种草：先用用户熟悉的痛点或欲望把人留下，再通过场景化体验让用户自然产生"原来我也需要这个东西"的感觉。重点：**场景 > 参数，体验 > 广告，需求建立 > 强行成交。**
- 普通卖货：最快速度让目标用户知道"这是什么、能解决我什么问题、为什么值得买"。核心：**需求 → 利益 → 证据 → 顾虑 → 行动。** 卖点必须翻译成用户利益。最高原则：**减少犹豫，提高决策效率。**
- IP 种草：不是"有人给我推荐一个产品"，而是"我理解为什么这个真实 IP 会选择/认可它"。重点说明为什么这个 IP 会选择它。只有 IP Fact 明确支持实际使用时，才能写"真的在用"。最高原则：**用 IP 信用给产品建立偏好，但不能透支 IP 信用。**
- IP 卖货：用 IP 已有的信任加速购买决策，同时保护长期信任资产。说清：为什么选它、筛选标准、适合谁/不适合谁、最大价值、需要提前知道的缺点、为什么这个价格值得。最高原则：**成交不能建立在透支 IP 信用之上。**

## 小红书（中心思想：参考价值）

让精准用户觉得"这是我要找的，而且值得参考/收藏"。核心资产：**搜索价值 + 真实体验 + 决策参考。**

- 普通内容：让用户觉得"这是我要找的，值得参考/收藏"。重点：搜索匹配 + 真实感 + 具体程度 + 收藏价值。
- 普通种草：让产品进入一个真实、具体、用户正在经历的生活场景，让用户自己得出"它可能适合我"的结论。优先使用使用前后、真实场景、优缺点、实测、对比、体验、避坑、适合/不适合人群。最高原则：**真实参考价值 > 广告感。**
- 普通卖货：帮助已经准备买的人做最后选择（用户可能已搜"XX哪个好/值得买吗/怎么选/和XX区别"）。内容重点是**决策信息**。最高原则：**像一份可信的购买攻略，而不是促销海报。**
- IP 内容：让用户觉得"这个人的品味/经验值得关注"。重点：品味、经验、审美、判断，产品可选。
- IP 种草：让用户因为认可这个人的生活方式、审美、经验和判断，而自然接受其产品选择。最高原则：**产品选择本身，就是 IP 的一部分。**
- IP 卖货：把 IP 长期积累的真实体验和选择标准，变成用户购买决策的可信依据。最高原则：**成交 + 人设强化同时完成。**

## 公众号（中心思想：认知与思想）

首先争夺用户的**深度阅读时间和认知信任**。不能只是展示商品，要让用户觉得"这件商品背后有一个值得理解的问题、需求、生活方式或判断逻辑"。

- 普通内容：SCQA / 故事→观点→论证 / 金字塔 / 冲突→判断→方法论。重点：观点新鲜度 + 逻辑完整 + 转发价值。
- 普通种草：先让用户理解一个需求、趋势、问题或生活方式，再让产品自然成为答案之一。最高原则：**先种认知，再种产品。**
- 普通卖货：用充分的信息、逻辑和证据完成一次理性的购买说服。最高原则：**把"我为什么应该买"讲透。**
- IP 内容：通过真实判断、价值观、观点输出思想与观点，让用户认同这个人；经历仅在来源明确时使用。**产品可选，不要求出现产品。** 最高原则：**先认同这个人的判断，再认同这个人的选择。**
- IP 种草：让用户先认同 IP 的判断，再认同 IP 的产品选择。最高原则：**判断认同 → 选择认同。**
- IP 卖货：用 IP 长期建立的判断力与信用完成深度成交，同时进一步强化 IP 价值观。最高原则：**不是"我有东西卖给你"，而是"基于我长期坚持的判断标准，我筛出了一个值得推荐的解决方案"。**

## 视频号（中心思想：信任与社交传播）

首先经营**可信度 + 共鸣 + 熟人传播**。内容最好让用户产生"有道理、这个人/这个东西靠谱、我想转给某个人看看"。

- 普通内容：让用户觉得"有道理、靠谱"，并想转给某个人。重点：可信度 + 共鸣 + 熟人传播。
- 普通种草：通过真实生活问题和可信解释，让产品成为值得推荐给身边人的解决方案。最高原则：**产品不仅值得自己考虑，还值得推荐给熟人。**
- 普通卖货：用可信、清楚、不夸张的方式完成购买说服。相比高刺激，**信任更重要**；相比喊口号，**证据更重要**。最高原则：**让用户放心买。**
- IP 内容：让用户信任这个人，并愿意看他的内容。重点：人设一致 + 可信度，产品可选。
- IP 种草：通过一个值得信赖的人，把一个值得信赖的产品介绍给用户。最理想状态：**IP 信任 → 产品信任**，同时**真实产品体验 → 反过来加强 IP 信任**。
- IP 卖货：把长期信任转化成成交，但绝不能用一次成交破坏长期信任。最高原则：**信任先于成交，长期价值高于一次 GMV。**

## 平台表达方向性说明（防伪精确）

- 短视频前段承担停止划走、识别目标用户和建立继续观看理由的任务，应尽快进入有效信息；具体秒数由平台规则、内容形式与用户阶段决定，不写死"必须 3 秒/5 秒"。
- 公众号标题显著影响打开意愿，但正文前段留存、内容价值和转发意愿共同影响传播表现；不写死"标题决定 80% 流量"。
- 小红书封面承担第二标题作用，但正文真实体验与关键词布局同样影响收录与转化；不写死固定比例。
- 只有真实硬限制（广告位字数、平台硬限制、用户明确长度、视频时长）才使用精确数字。

## 四平台原生真人感（成品标准）

> 平台规律决定"用户怎么消费内容"，原生真人感决定"成品像不像这个平台上的人"。完整成品层规则见 `final-output.md`（Source of Truth：成品真人感与平台原生层）。

### 抖音：正在发生

真人感核心是**正在发生**，不是"在介绍一个产品"，而是"人在拿、拆、试、看、问、判断"。

- 优先：动作 / 现场 / 反应 / 用户问题 / 一句判断。
- 尽量寻找 1-3 个真实可拍动作（拿起 / 拆开 / 倒出来 / 对比 / 泡 / 闻 / 看 / 试）。
- 连续 80 字以上只有对镜头干讲：优先重构。
- 成品感觉：像人在镜头前边做边说。

### 小红书：帮用户做选择

真人感核心是**帮用户做选择**，不是"广告装成分享"，而是"我把真实选择逻辑给你"。

- 重点：为什么选 / 为什么不选 / 适合谁 / 不适合谁 / 真实优点 / 必要缺点 / 使用场景 / 对比 / 避坑 / 细节。
- 不要靠"姐妹们、绝绝子、闭眼冲"制造平台感。
- 成品感觉：像真实的人在帮我做选择。

### 公众号：有人真的想过这件事

真人感核心是**有人真的想过这件事**，不是口语化。允许书面表达，但必须有：主观点 / 判断 / 推进 / 解释 / 案例 / 思考。

- 禁止写成 AI 资料整理。
- 每部分都必须推动主观点。
- 成品感觉：像一个作者真正想明白以后写出来。

### 视频号：现实中值得信任的人

真人感核心是**现实中值得信任的人**，更像老板 / 老师 / 专业人士 / 有阅历的人 / 家庭里的可靠角色。

- 减少：猛刺激 / 猛反转 / 极端话 / 网络热梗。
- 增加：稳定判断 / 解释 / 现实场景 / 熟人传播价值；经历仅在 IP Fact Source 支持时使用。
- 视频号绝不能只是"放慢语速的抖音"。
- 成品感觉：像现实中一个值得信任的人在讲话。

## 平台角度发现指引（v2.7）

> 完整规则见 `dynamic-angle-discovery.md`（Source of Truth：动态角度发现引擎）。**平台从选题阶段就要介入，不能先选 5 个角度再做平台适配。** 以下指引用于拓宽角度搜索空间，不是"每次必须选一篇"的固定栏目。

### 抖音：能不能拍出来？

优先选择有视觉动作 / 有现场变化 / 容易快速理解 / 能制造继续观看理由 / 用户问题明确 / 能现场验证 / 有人物判断 的角度。

- 角度不只是"知识有没有价值"，还要考虑：**能不能拍出来？**（拿起/拆开/倒出来/对比/泡/闻/看/试）
- 抖音角度 + Natural Depth：不是多讲，而是保证**观看推进 + 人物判断 + 当前任务心理变化**，防止短句产品卡片化。

### 小红书：用户以后做决定时会不会回来找这篇？

优先选择搜索问题 / 购买比较 / 选择标准 / 使用细节 / 适合-不适合 / 实际决策 / 避坑 / 可收藏 的角度。

- 核心：**用户以后做决定时会不会回来找这篇？**
- 小红书角度 + Natural Depth：必须给用户足够参考信息，防止为了"像真人笔记"写得过碎、过浅。

### 公众号：这件事有什么值得被真正想明白？

优先选择认知问题 / 消费判断 / 品类背后逻辑 / 产品选择哲学 / IP 长期观点 / 用户为什么会形成错误判断 / 生活方式与价值选择 的角度。

- 核心：**这件事有什么值得被真正想明白？**
- 公众号角度 + Natural Depth：观点必须真正被论证，防止为了"不套三段式"导致只有观点没有展开。

### 视频号：这是不是一句值得现实中转给别人听的话？

优先选择信任判断 / 现实生活问题 / 熟人关系 / 有阅历的选择逻辑 / 家庭-朋友可转述问题 / 产品是否靠谱 / 长期信用 的角度。

- 核心：**这是不是一句值得现实中转给别人听的话？**
- 视频号角度 + Natural Depth：必须让用户**听懂 + 相信 + 能转述**，防止"克制"变成"平淡"。

### 跨平台不能共用同一 Top 5

同一个产品：抖音 5 版 / 小红书 5 版 / 公众号 5 版 / 视频号 5 版，**不得先生成同样 5 个 Angle 再换平台语言**。平台从 Angle Discovery 开始就不同。
