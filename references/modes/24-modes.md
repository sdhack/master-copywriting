# 24 模式中心思想与评分标准（references/24-modes.md）

> **Source of Truth：24 模式中心思想。** 主 SKILL.md 只保留 Router 简要调用；本文件是 24 模式中心思想的唯一 Source of Truth。
> 24 模式 = 4 平台 × 2 类型（普通/IP）× 3 目的（内容/种草/卖货）。
> 每种模式必须体现平台差异、普通/IP 差异、内容/种草/卖货差异，不是换几个词。
> 24 模式 = 中心思想层，不扩容。用户阶段、内容形式、人群、第一目标、商业关系都是执行修饰变量，不扩大模式矩阵。

## 三、模式优先级（第一核心目标）

- **普通内容**：点击/停留/完播/阅读/收藏/评论/转发/关注/IP 认知。不要求必须出现商品。
- **普通种草**：需求建立 > 产品理解 > 产品偏好。**Seed 不以即时成交作为目标。**
- **普通卖货**：需求匹配 > 利益清晰 > 信任证明 > 顾虑解除 > Decision Readiness（完成购买判断；不要求正文告诉用户点击哪里）。
- **IP 内容**：内容价值 + IP 认知。**产品可选，不要求出现产品。**
- **IP 种草**：内容价值 + IP 认知 + 产品偏好。
- **IP 卖货**：用户利益 + IP 信用 + 产品价值 + 成交。任何为提高成交而伤害 IP 长期信任的表达都应删除。

**24 模式边界（防漂移）**：

- **内容型**：不要求出现产品。
- **种草型**：建立想要与偏好。
- **卖货型**：帮助完成决定。
- **IP 内容**：内容价值 + IP 认知，产品可选。
- **IP 种草**：内容价值 + IP 认知 + 产品偏好。
- **IP 卖货**：用户利益 + IP 信用 + 产品价值 + 决策。

## 四、行为锚点评分（0 / 1 / 2 三级）

> 自检时不用"停留 9 分 / 信任 8 分"式主观打分。每个指标使用 0/1/2 三级评分：
> **0 = 不合格**（目标几乎没有实现）；**1 = 基本存在**（已出现但弱、泛或不充分）；**2 = 明确成立**（具体、可验证、直接服务第一目标）。

通用锚点：

| 指标 | 0 | 1 | 2 |
|---|---|---|---|
| IP 辨识度 | 换任何同行说都成立 | 有部分个人观点或表达风格 | 明确体现该 IP 独特的经历/判断标准/方法/性格/价值观之一 |
| 证据 | 只有自夸 | 存在依据，但泛泛 | 有与核心主张直接匹配的具体、真实、可验证证据 |
| 产品偏好 | 看完不知道为什么选它 | 知道部分优势 | 用户能清楚说出"这个产品在我的场景下为什么更值得考虑" |
| 需求建立 | 没有唤起任何需求 | 提到需求但泛泛 | 用户能代入"我确实有这个问题/想要这个状态" |
| 决策信息 | 没有足够信息判断是否选择当前方案/SKU | 有部分信息 | 用户已经拥有足够信息判断是否选择当前方案/SKU |

规则：

- 任一核心指标 = 0，必须修改。
- 优先修改最影响第一目标的指标。
- 不追求所有指标都是 2。

## 五、24 模式成品感觉（用户最终应该感觉到什么）

> 成品感觉 = 用户看完后最强烈的那一句感受。自检时问：用户是否会产生这一句感觉？如果没有，说明成品没有达到模式目标。
