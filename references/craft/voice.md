# 语气基线（references/voice.md）

> **Source of Truth：表达风格。** 来源：`ecommerce-copywriting-book-library` 的资深策划语气基线。
> 用法：去 AI 味时参考。**不要使用过度机械的统一数字标准**，量化基线仅作参考，按平台与形式调整。自然语言优先于量化形式指标。

## 一、资深策划语气基线（关键指标）

从 113 本书 38025 片段中检索到的 6 段高质量文案正文，提取表达分布作为语气锚点：

| 指标 | 目标区间（方向性） | 说明 |
|---|---|---|
| 平均句长 | 22.2 - 32.5 字 | 参考区间，不追求极端短句，也不写超长句；不强制固定句长 |
| 判断句占比 | 0 - 25% | 有判断力但不通篇下结论 |
| 具体细节密度 | 0 - 3.16 个/100 字 | 具体细节是去 AI 味的关键 |
| 短句占比 | 0 - 14.3% | 少量短句点缀节奏 |
| 长句占比 | 20% - 75% | 允许一定比例长句承载信息 |
| 第一人称 | 0 - 1.77 次/100 字 | 不滥用"我"，但允许自然出现；不强制固定次数 |
| 抽象词密度 | 避免空泛抽象词 | 不设强制为 0，以"是否空泛"判断 |
| 转折词密度 | 0 - 0.77 个/100 字 | 自然转折，不堆砌 |
| 证据句占比 | 0 - 20% | 有证据支撑，不空口 |
| 段落数 | 短文案参考 2-3 段 | 长文按需调整，不强制固定段数 |
| 产品出现位置 | 0 - 0.95（前段到后段） | 按用户阶段决定产品出现时机 |

**使用注意**：这些区间是资深策划基线，不是硬性门槛。按平台与形式调整：抖音口播可更短句、更口语；公众号长文可更长句、更多段落；小红书可更多具体细节。**自然语言优先于量化形式指标。**

## 二、去 AI 味重点检查（按平台与形式调整）

- 是否大量使用"首先、其次、最后"
- 是否重复解释同一意思
- 是否出现空泛正确话
- 是否大量排比
- 是否每句话都非常工整
- 是否过度使用"不是 A，而是 B"
- 是否大量"真正的……"
- 是否大量"你知道吗"
- 是否一眼看出套公式
- 是否出现模型自我说明
- 是否出现无真实信息的强观点
- 是否不像真实目标人群会说的话

## 三、语气分层（按内容形式）

| 形式 | 语气倾向 | 说明 |
|---|---|---|
| 抖音口播 | 短句、口语、节奏快 | 前 3 秒抓人，信息密度高 |
| 小红书图文 | 具体、真实、利他 | 细节丰富，像真实体验分享 |
| 公众号长文 | 有观点、有逻辑、有深度 | 允许长句与段落，认知增量 |
| 视频号 | 亲和、可信、像熟人说话 | 信任优先，不夸张 |
| 直播话术 | 口语化、互动感、有节奏 | 留人→互动→成交→追单→转款 |
| 信息流广告 | 直接、聚焦、单一目标 | 压缩说服，减少摩擦 |
| 详情页/落地页 | 结构化、证据化、低摩擦 | 利益→证据→异议→行动 |
| 私域朋友圈 | 生活化、价值分层 | IP 表达+信任+种草+互动+转化交替 |

## 四、表达堆叠红线

- 禁止并列 ≥2 个同类标记在同一句或短窗口（30 字内）：元话语标记（"说实话""讲真"）、转折连接词（"但是""不过""然而"）、称呼词（"老哥""家人们"）、夸张词。
- 开场句禁止 ≥2 个地址/阻拦式/元话语标记，只留一个抓手 + 一个承接。
- 同批次各版的开头句式、收口动作词与理由不得重复。
- 避免过度使用留人/挽留式开头（"别划走/先别划走/别急着划走/先别走/别滑走"）；单批次至多出现一次且不得与上一版同一句式，优先使用信息型/场景型/疑问型开场。
