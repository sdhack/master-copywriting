# 钩子库（references/hooks.md）

> **Source of Truth：钩子。** 来源：ecommerce-copywriting-book-library 的黄金三秒开头资产库（golden-opening/golden-opening.jsonl）。
> 钩子 = 前段让用户"停下来"的抓手。**先路由钩子机制，再从机制生成，禁止复制示例原句或仅换词。**
> 钩子必须满足：**机制 × 真实事实 × 平台表达。**

## 钩子安全标签（选钩子前必看）

- **SAFE**：默认可用。场景 / 信息差 / 对比 / 选择标准 / 真实体验 / 明确利益 / 真实证据。
- **CONDITIONAL**：只有满足事实条件时才能使用。限时 / 限量 / 销量 / 复购 / 用户数据 / 权威背书 / 第一人称经历 / 实测 / 价格对比 / 原价 / 折扣 / 产地 / 认证。使用前必须检查事实表。
- **AVOID / LEGACY**：保留研究价值，默认不参与自动生成。手慢无 / 炸单 / 废掉一个人最好的方式 / 99% 的人 / 90% 的人 / 所有人都 / 只有这一种 / 最好 / 第一 / 唯一 / 无依据恐吓 / 极端焦虑 / 虚假稀缺 / 机械主播黑话。默认路由不得召回。

## 钩子使用规则

- **机制词写进首句**：提问式带"你是不是/为什么/你有没有"且句末问号；对比式带"区别/对比/为什么有的"；场景式带"家里/夏天/茶桌/待客"等。
- **宽入口**：首句从生活/使用场景、购买判断问题、对比关系、可见变化、具体使用任务中选择一种，再落到平台原生证据；禁止从叶底、毫升、水温等孤立参数直接起句。
- **安全标签**：SAFE 默认可用；CONDITIONAL 使用前必须检查事实表；AVOID/LEGACY 默认路由不得召回。
- **批量差异（Creative Variation 适用）**：同一开头语义家族最多占批次 20%；同批各版不得用同一开头模板，不得只换近义词。
- **A/B 例外**：A/B 单变量测试只改变被测试变量（如钩子），正文、证据、CTA 保持一致；此时"同批各版不得用同一开头模板"不适用，批量差异化规则让位于 A/B 单变量原则。
- **禁止钩子三连拼**：场景+人群+悬念三类成分不得同句并列，开头只留一个抓手+一个承接。
- **钩子必须现场生成**：只迁移机制/公式/结构，禁止复制库中示例原句或仅换词；钩子由"所选机制 × 产品事实 × 表达"生成。
- **钩子红线**：禁止为钩子编造数字（"90% 的人""99% 的人"）、虚假成功案例、假装亲身体验、无法证明的结果、单纯夸张制造焦虑；钩子承诺必须在正文兑现。
