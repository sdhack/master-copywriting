# 结构演示型例句（references/examples.md）

> **Source of Truth：示例。** 用途：示例用于帮助理解机制，**不应该诱导 AI 模仿夸张事实**。
> 所有例句均为"结构演示"——展示句式骨架如何承载真实事实，数字/经历/结果均为占位或安全示例，**禁止原句照抄，禁止迁移到其他产品**。
> 凡出现"90%/99%/巨大结果/虚假销量/虚假成功案例/医疗功效/无依据专家/虚假证言/虚假限时限量/无依据第一唯一最好/假第一人称经历"的示例，一律替换为安全的结构演示。

## 一、钩子结构演示（安全版）

> 占位符【】表示必须用真实事实填充。禁止编造数字与经历。

| 机制 | 结构演示 | 说明 |
|---|---|---|
| 场景 | 【某类人群】在【具体场景】里，最常遇到的一个问题是【真实问题】 | 用真实场景替代夸张 |
| 反常识 | 很多人以为【常见认知】，其实【可验证的真相】 | 真相必须可验证 |
| 信息差 | 挑【品类】时，多数人只看【表面维度】，却忽略了【关键维度】 | 维度必须真实 |
| 选择判断 | 买【品类】前，先想清楚【一个关键问题】，再决定 | 帮助决策而非制造焦虑 |
| 结果 | 用了【真实方法】后，【可观察的变化】 | 变化必须可验证 |
| 身份 | 【人群】在【场景】里，最在意的是【真实诉求】 | 诉求必须真实 |

**禁止示例（原危险例句 → 问题）**：
- "90% 的人都不知道……" → 编造比例
- "我用了三年，终于……" → 假第一人称经历
- "月薪 3000，一年存了 10 万" → 虚假结果

## 二、主结构演示（安全版）

### 抖音普通卖货（PAS）
- 结构演示：P【目标人群在场景里的真实问题】→ A【问题不解决带来的真实不便】→ S【产品如何对应解决，用可验证事实】
- 安全示例（占位）："挑【品类】最怕【真实痛点】。不解决，【真实不便】。这款【产品】用【可验证事实】对应解决。"

### 小红书普通种草（BAB）
- 结构演示：B【使用前的真实状态】→ A【使用后的可观察状态】→ B【产品如何连接两者】
- 安全示例（占位）："之前【真实状态】。现在【可观察状态】。靠的是【产品事实】。"

### 公众号 IP 内容（SCQA）
- 结构演示：S【普遍情境】→ C【情境中的真实冲突】→ Q【聚焦一个关键问题】→ A【IP 的判断与论证】
- 安全示例（占位）："【普遍情境】里，【真实冲突】。问题是【关键问题】。我的判断是【观点】，理由是【论证】。"

### 视频号 IP 卖货（The 3 Whys）
- 结构演示：Why you【差异化事实】→ Why now【真实时机】→ Why trust【可验证证据】
- 安全示例（占位）："为什么选它？【差异化事实】。为什么现在？【真实时机】。凭什么信？【可验证证据】。"

## 三、CTA 结构演示（安全版）

| 口径 | 结构演示 | 说明 |
|---|---|---|
| 看播 | 【价值预告】，想【了解什么】的，进直播间来看 | 抽象价值预告，不描述直播间行为 |
| 预约 | 想不错过【内容主题】，下方预约点一下，开播我提醒你 | 仅预告开播时间时用 |
| 成交 | 【购买判断】，是否适合【场景】，按自己的【条件】决定 | 完成购买判断，不硬推 |
| 留资 | 【人数/预算/频率】不同，具体方案按实际情况再定 | 形成适配问题，不强咨询 |
| 无指令 | 【判断句/画面】收尾 | 不指令，让价值自然落地 |

**禁止示例**：
- "赶紧下单""手慢无""仅剩最后 X 单" → 生硬命令/虚假稀缺
- "点击下方购物车预约，开播我等你" → 组件名直念

## 四、平台原生表达演示（安全版）

| 平台 | 结构演示 | 说明 |
|---|---|---|
| 抖音 | 前 3 秒【一个真实钩子】→ 正文【一个信息增量】→ 结尾【一个自然收束】 | 注意力优先 |
| 小红书 | 标题【搜索关键词+价值】→ 正文【真实体验+具体细节】→ 结尾【收藏/轻承接】 | 参考价值优先 |
| 公众号 | 标题【观点+悬念】→ 开头【冲突/场景】→ 正文【论证】→ 结尾【互动/转发】 | 认知优先 |
| 视频号 | 开头【可信问题】→ 正文【可信解释】→ 结尾【转发/信任收束】 | 信任优先 |

## 五、IP 内容真实性演示（安全版）

**没有经历素材时，宁可使用判断、观察、假设场景，也不能伪造第一人称经历。**

| 场景 | 安全写法 | 禁止写法 |
|---|---|---|
| 无使用经历 | "按我的判断标准，【标准】很重要" | "我用了三年" |
| 无行业背景 | "我观察到的现象是【可观察现象】" | "我做这行 20 年" |
| 无客户反馈 | "如果按【标准】来挑，会【合理结果】" | "客户都这么说" |
| 无亲测数据 | "假设场景是【场景】，这时【合理判断】" | "我去年才发现" |

## 六、使用红线

- 示例是结构演示，不是可照抄的文案。禁止复制示例原句或仅换词。
- 示例中的数字/经历/结果均为占位，必须用真实产品事实替换。
- 钩子承诺必须在正文兑现。
- 公式是工具，不是创作起点；先事实，再说服。
