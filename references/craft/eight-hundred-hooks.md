# 800个短视频爆款开头钩子（references/craft/eight-hundred-hooks.md）

> **Source of Truth：第三方数据中心 PDF《800个短视频爆款开头钩子》拆解（2026-08 抓取）。**
> 版本：v1.0（v4.17.0 新增）。
> 用途：短视频/直播引流素材开头钩子生成，按「大类 × 机制 × 安全标签」提供模板化句式。
> 边界：本库是**句式模板库**，不是实证原句库；**禁止直接复制原句/仅换词**，只迁移结构，结合产品事实现场生成。

---

## 安全标签复用（same as hooks.md）

- **SAFE**：默认可用。场景 / 信息差 / 对比 / 选择标准 / 真实体验 / 明确利益 / 真实证据。
- **CONDITIONAL**：只有满足事实条件时才能使用。限时 / 限量 / 销量 / 复购 / 用户数据 / 权威背书 / 第一人称经历 / 实测 / 价格对比 / 原价 / 折扣 / 产地 / 认证。使用前必须检查事实表。
- **AVOID**：保留研究价值，默认不参与自动生成。手慢无 / 炸单 / 废掉一个人最好的方式 / 99% 的人 / 90% 的人 / 所有人都 / 只有这一种 / 最好 / 第一 / 唯一 / 无依据恐吓 / 极端焦虑 / 虚假稀缺 / 机械主播黑话。默认路由不得召回。

## 使用规则（复用 hooks.md 体系）

- **安全标签复用 same as hooks.md**：SAFE/CONDITIONAL/AVOID
- **禁止复制原句**：本库是模板句式库，只迁移结构，结合产品事实现场生成具体钩子
- **宽入口优先**：开头直接带身份/场景/痛点关键词，让目标用户"对号入座"
- **批量差异化**：同一语义家族在同批不得超过 20%；模板结构差异化远重于近义词替换
- **组合规则**：可以叠加 1-2 个套路（比如人群定向 + 痛点共鸣），符合 gold3s 数据库的组合结论（71% 组合占比）
- **钩子红线**：禁止编造数字、虚假成功案例、假装亲身体验，必须基于事实
