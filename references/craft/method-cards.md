## 一、M1-M8 意图 → 方法卡映射

| 意图 | 一句话 | 何时用 | 对应方法卡 |
|---|---|---|---|
| **M1 文案基本功**（怎么写对） | 标题是第一道门；写"读者好处"非"产品卖点"；具体才有说服力；结构像滑梯一句带一句；诚实是底线 | 写标题/开头/钩子；让文案更具体；未指定平台 | `title-writing`、`copy-formula`、`copy-rubric-review`、`feature-benefit-scenario`、`pain-point-mining` |
| **M2 卖货文案**（促成交） | 五步框架：吸睛标题→勾魂开场→激发欲望→塑造信任→成交下单；卖点转利益；证据链建信任；价格锚定/诱饵/稀缺 | 卖货/带货/收钱文案；提高转化；详情页/直播成交 | `offer-value-stack`、`evidence-risk-reversal`、`price-anchoring`、`landing-page-copy`、`livestream-selling`、`method-human-cta-translation` |
| **M3 广告创意**（有记忆点） | 创意=旧元素新组合；洞见胜过创意；黏性六原则 SUCCESs；创意服务销售 | 想创意/点子；让内容有黏性/被记住/易传播 | `emotional-resonance`、`visual-storyboard`、`holiday-hotspot`、`category-creation` |
| **M4 故事化**（讲动人） | 主题先行→人物→冲突→结构（激励事件→升级→转折→结局）；展示而非告诉；目的导向 | 写品牌/产品/人物故事；让内容有情节/张力 | `story-conflict-proof`、`brand-narrative` |
| **M5 说服心理**（为什么买） | 快思考先行；六大影响力武器（互惠/承诺一致/社会认同/喜好/权威/稀缺）；锚定/损失厌恶/诱饵/羊群 | 让文案更有说服力/可信；用消费心理/影响力；价值感知 | `consumer-psychology`、`criteria-differentiation`、`authority-credibility`、`social-proof`、`price-anchoring`、`fear-urgency` |
| **M6 品牌定位**（站住心智） | 终极战场在心智；定位聚焦极简；第一胜过更好；超级符号+视觉锤；品牌资产长期沉淀 | 品牌定位/主张/slogan；超级符号/品牌口号；品牌故事 | `positioning-value-proposition`、`brand-narrative`、`category-creation`、`account-growth` |
| **M7 增长运营**（流量与裂变） | 增长漏斗 AARRR；北极星指标；流量池思维（公域→私域→变现）；社交裂变分享驱动；运营闭环 | 引流/获客/拉新；私域/社群/增长；裂变/转介绍/分享有礼 | `account-growth`、`content-planning`、`retention-loyalty`、`recommendation-referral`、`word-of-mouth-viral`、`influencer-collaboration`、`local-life`、`persona-segmentation`、`data-driven-creation`、`five-a-customer-path-content`、`customer-journey` |
| **M8 思维表达**（想清楚写清楚） | 结论先行/MECE/SCQA；上瘾模型；参与感；关键对话安全沟通；数据验证 | 写得有条理/结构清晰；让用户上瘾/习惯；用数据验证文案 | `content-goal-router`、`audience-core-tension`、`criteria-differentiation`、`ux-five-plane-landing-page`、`customer-value-creation-dialogue`、`business-model-message-fit`、`crucial-dialogue-safety-facts-path`、`ab-test-single-variable`、`data-driven-creation` |

## 三、组合模板（起点，最终以实际路由为准）

- 抖音带货视频：平台抖音 + M2 卖货 + M5 说服 + M6 品牌 → `offer-value-stack` + `authority-credibility` + `positioning-value-proposition`
- 小红书种草笔记：平台小红书 + M1 基本功 + M4 故事 → `feature-benefit-scenario` + `story-conflict-proof`
- 公众号卖货软文：平台公众号 + M2 卖货 + M4 故事 + M8 思维表达 → `offer-value-stack` + `story-conflict-proof` + `content-goal-router`
- 视频号私域引流：平台视频号 + M7 增长 + M5 说服 → `retention-loyalty` + `social-proof`
- 品牌新品发布会文案：M6 品牌 + M3 创意 + M4 故事 → `positioning-value-proposition` + `emotional-resonance` + `brand-narrative`

## 使用红线

- M1-M8 只做方法定位，禁止借此迁移书中案例、数字、人物或产品结论。
- 主方法控制骨架，辅助方法只解决局部阻力，不得堆叠（最多 1 主 + 1 辅助）。
- 反例卡与合规边界卡始终由合规门禁调用，不得绕过。
