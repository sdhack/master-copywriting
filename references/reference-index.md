## Single Source of Truth Rules

1. **Canonical rules live only in references/.** No adapter may copy, modify, or redefine canonical rules.
2. **Adapters map capabilities, they don't rewrite logic.**
3. **If a rule exists in references/, that is the truth.** Any adapter claiming otherwise is wrong.
4. **New rules get added to the canonical reference,** never added to individual adapters first.
5. **Version changes propagate to all adapters** via the same canonical package.

## Progressive Disclosure Optimization

Load order:
1. Core execution rules first (always needed)
2. Then platform/mode rules (if platform is known)
3. Then purpose-specific rules (if purpose is known)
4. Then quality/craft references (as needed)
5. Then examples (only if stuck or learning)

**Never load all references at once.**
