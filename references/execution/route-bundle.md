# Minimal Route Bundle Contract

A route bundle is a manifest, not a concatenation of references. It contains the normalized route, selected reference paths, required gates, humanization stages, output contract, and exclusions.

Always include execution reliability, audit severity, humanization, final output, and CTA. Add platform, purpose, cross-platform, voice, product acquisition, or claim references only when the route needs them.

The compiler must be deterministic: identical route JSON produces an identical manifest. Unknown route values fail clearly instead of loading the entire library.
