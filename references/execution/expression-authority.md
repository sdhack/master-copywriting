# 表达权威层 Expression Authority（references/expression-authority.md）

> **Source of Truth：表达权威层 Expression Authority。** 主 SKILL.md 只保留简要调用；本文件是 Expression Authority 的唯一 Source of Truth。
> 适用范围：**所有平台、所有类型（普通/IP）、所有目的（内容/种草/卖货）的跨 Skill 统一数据边界。**
> 解决：产品事实越说越大、从一个真实卖点自动长出新的卖点、为真人感虚构 IP 经历、为专业感制造绝对判断、为卖货贬低其他产品、为场景成立自动补功效、为内容完整度增加未经提供的信息、为多版本差异制造不同虚假经历、为平台感过度使用刻板话术。
> 最高原则：**允许 AI 把真实事实说活，但不允许 AI 把真实事实说大。事实边界硬，表达空间宽。**
> 总纲：**产品 Skill 负责事实；人物资料负责经历；Master Copywriting 负责选择和表达；平台决定表达方式；目标决定推进程度；Humanization 只能把话说活，不能把事实说大。**

---

## 一、三个信息源（Cross-Skill 数据边界）

Master Copywriting 必须明确区分三个信息源，三者不得越权：

### 1. Product Fact Source（产品事实源）

**来自**：产品 Sell-point Skill / 商品资料 / 品牌提供的真实资料。

**负责**：产品是什么。包括：产品规格、工艺、原料、价格、包装、香气、口感、使用方式、使用场景、已确认利益点、售后、优惠、SKU 具体表现。

**当用户明确说明"Sell-point Skill 中的信息全部真实有效"时**：这些内容视为**可直接使用的 SKU 事实**，Master Copywriting 无需重复质疑。

### 2. IP Fact Source（IP 事实源）

**来自**：IP 人物资料 / 创始人资料 / 用户提供的真实经历 / 真实访谈 / 账号历史内容 / 用户明确确认的人物事实。

**负责**：这个人真实发生过什么。包括：做了多少年、去过哪里、见过谁、用过什么、平时怎么做、自己真实习惯、朋友/客户真实事件、家庭经历、经营经历。

### 3. Platform / Writing Knowledge（平台写作知识）

**来自**：Master Copywriting。

**负责**：怎么表达。包括：平台表达、结构、钩子、节奏、CTA、内容取舍、顺序、真人感、用户心理。

**它不能创造**：产品事实、IP 人生事实。

---

## 二、最高层跨 Skill 原则

统一写入：

> **Sell-point Skill 决定"什么是真的"。**
> **IP 资料决定"这个人真实经历过什么"。**
> **Master Copywriting 决定"这篇选什么、怎么说"。**
> **三者不得越权。**

尤其：

- 文案结构不能创造事实
- 平台原生化不能创造事实
- Humanization Pass 不能创造事实
- Creative Variation 不能创造事实
- CTA 不能创造事实
- IP 塑造不能创造经历

---

## 三、Expression Authority 四级权限

Master Copywriting 读取真实事实以后，只允许以下四种处理：

### LEVEL 1 · REPHRASE（改写）

可以改变语言形式，不能改变事实含义。

| 原始事实 | 允许 | 禁止 |
|---|---|---|
| 兰花香明显 | 兰花香比较清楚 | 满屋子全是兰花香 |
| 兰花香明显 | 水一进去，兰花香很快能闻到 | 除非原资料明确支持 |

### LEVEL 2 · CONTEXTUALIZE（场景化）

可以把事实放进合理场景，前提是不能新增未经提供的结果。

| 原始事实 | 允许 | 禁止 |
|---|---|---|
| 可以冷泡 | 夏天不想喝热茶的时候，可以换成冷泡 | 所以永远不会泡浓 |
| 一颗一泡 | 出门带几颗，不用每次称茶 | 所以更省钱 / 更卫生 / 更锁鲜 |

### LEVEL 3 · INTERPRET（IP 判断）

允许 IP 对事实表达：判断、偏好、筛选标准、取舍、推荐理由。

例如：

> 我挑水仙，更看重香气能不能落到水里。

这是 **IP 判断**。但必须表达为"我的标准"，不能自动升级成"所有好水仙都必须这样"。

### LEVEL 4 · FACT EXPANSION（禁止）

Master Copywriting 不得基于一个真实事实继续创造新的事实。

| 原始事实 | 禁止自行扩成 |
|---|---|
| 冷泡清爽 | 不长胖 / 解腻 / 提神 / 不苦涩 / 永远不会泡过头 / 对身体更好 |
| 手工制作 | 机器做的一定不好 |
| 一颗一泡 | 更省钱 / 更卫生 / 更锁鲜 / 更适合旅行 / 永远不会泡浓 |

除非 Sell-point Skill 明确提供。

## 四、事实扩张测试（每句必问）

每生成一句涉及产品的内容，内部追问：

> 这句话相比原始产品事实，增加了什么新的信息？

如果只改变：说法、顺序、场景、比喻、用户理解方式 → **可以**。

如果新增：新效果、新功效、新优势、新结果、新适合人群、新价格判断、新市场比较、新产品因果关系 → **必须检查 Sell-point Skill**。

找不到 → **删除**。

---

## 五、IP Fact Firewall（IP 事实防火墙）

真人感不得通过虚构人生实现。以下表达生成前必须检查 IP Fact Source：

我第一次… / 我以前… / 我喝了很多年… / 我每天… / 我家里常备… / 我夏天一直… / 我去过… / 我亲眼见过… / 我跟某某老师… / 我朋友… / 我客户… / 我妈… / 我老婆… / 我孩子… / 我上次送… / 有个粉丝跟我说…

**如果 IP 资料不存在：禁止生成。即使相关产品事实是真的。**

---

## 六、真人感的替代方案（没有真实人物经历时）

优先通过以下方式制造真人感：

1. **判断**：我更看重……
2. **选择**：这种茶我会先看……
3. **取舍**：我宁可少一个卖点，也不会……
4. **边界**：喜欢清香型的，这款未必适合你。
5. **现场动作**：你看，我把这一颗拆开。
6. **用户问题**：很多人第一次看到都会问……（前提确有普遍场景依据，不能伪造具体客户事件）
7. **产品观察**：泡开以后你可以自己看。

真人感来自**怎么判断**，不是**编发生过什么**。

---

## 七、Professional Humility（专业谦逊）

专业 IP 必须有边界。AI 目前容易为了"像专家"写：

- 一看就知道
- 这个骗不了
- 这样就是好
- 不这样就是差
- 别人学不来
- 机器一定不行
- 这个指标就能判断品质
- 一喝就知道
- 真正懂行的人都……

统一限制。优先表达：

- 我自己通常会看……
- 这是我判断的其中一项。
- 单看这一项其实还不够。
- 不同工艺会有不同表现。
- 这个标准更适合我自己的筛选逻辑。

---

## 八、专业感的核心不是"确定"，而是"有判断边界"

越专业，越允许"不绝对"。高质量专业 IP 应该知道：

- 什么可以判断
- 什么不能只靠一个指标判断
- 什么只是自己的偏好
- 什么存在不同做法
- 什么需要结合其他因素

**禁止为了短视频传播，把复杂专业知识强行压缩成错误二元结论。**

---

## 九、Competitive Restraint（竞争克制）

证明自己的产品好，优先使用：

- 产品事实
- 真实证据
- SKU 表现
- 工艺
- 用户需求匹配
- IP 筛选标准

不要无依据贬低：机器产品、低价产品、其他品牌、其他工艺、散茶、通货、同行、市面产品。

**核心原则：证明自己好，不等于必须证明别人差。**

如果确实需要对比，必须：

- 有明确事实依据
- 对比维度一致
- 不扩大结论
- 不攻击整个品类

---

## 十、产品事实 ≠ 行业定律

| 当前产品事实 | 可以说 | 不能自动推出 |
|---|---|---|
| 叶底有绿叶红镶边 | 这款叶底是绿叶红镶边 | 所有好乌龙必须绿叶红镶边 |
| 手工压制 | 这款是手工压的 | 机器压的一定不好 |
| 焙火 | 这款焙过火 | 抽湿工艺都是差茶 |

**SKU 证明 SKU，不得自动证明整个行业。**

---

## 十一、四平台全部应用 Expression Authority

规则统一，但不同平台重点不同。

### 抖音

最大风险：为了强钩子、冲突、真人口播、现场感，把事实说得更猛。

**抖音允许表达强，但不允许事实变强。** 例如可以更有节奏，但不能把"香气明显"变成"整个屋子都是香"，除非事实支持。

### 小红书

最大风险：为了"真实体验感"自动生成"我用了一个月 / 实测 / 回购第三次 / 闺蜜问链接 / 我妈也喜欢"。

**禁止。** 小红书真人感来自：细节、选择逻辑、优缺点、适合/不适合、使用方法。不是虚构使用经历。

### 公众号

最大风险：为了故事感、思想深度、情绪推进，编造客户故事、创始人故事、行业案例、亲身经历、对话。

**禁止。** 公众号允许**观点深**，不代表**故事可以编**。

### 视频号

最大风险：为了阅历感、信任感、人情味，虚构"我做这一行几十年 / 有一次一个老客户 / 我父亲以前"。

**除非 IP 事实源存在。** 视频号可信感来自：**稳定判断 + 边界 + 人格一致性**。不是虚构人生厚度。

---

## 十二、普通 / IP 分别处理

### 普通内容

禁止为了真人感硬加"我……"。普通内容的自然感来自：场景、具体、节奏、用户问题、信息价值。

### IP 内容

至少出现一个**人格动作**：判断、选择、拒绝、坚持、取舍、偏好、方法。但人格动作不等于人物经历。

---

## 十三、内容 / 种草 / 卖货分别处理

### 内容

允许不卖。不要为了完整度强塞商品利益。

### 种草

重点：为什么值得考虑。允许留白。不得为了建立喜欢自动夸大体验。

### 卖货

必须回答：为什么是它、谁适合、什么证据、有什么决策理由、下一步是什么。

**但是：卖货也没有新增事实权。**

---

## 十四、适合/不适合权限控制

AI 非常容易自动写：长辈适合、宝妈适合、新手适合、所有人适合、送客户适合、不挑人。

这些属于**新的用户适配事实**。如果上游没有支持，不能写成确定结论。

可以写成条件判断：

> 如果你平时喜欢焙火香明显的乌龙，可以考虑。

这是基于**需求匹配**，不是**泛人群承诺**。

---

## 十五、多版本 Creative Variation 不能靠"编五段不同人生"

用户要求 5 版时，禁止为了差异化生成：版本1"我第一次…"、版本2"我朋友…"、版本3"我妈…"、版本4"我客户…"、版本5"我去年…"。如果没有事实源，全部禁止。

多版本差异来自：

- 核心问题
- 核心判断
- 用户场景
- 内容驱动力
- 产品事实
- 证据
- 表达姿态
- 产品出现时机

而不是不同虚构故事。

---

## 十六、Expansion Budget（扩展预算）

每个原始卖点允许：

- 1 次主要表达
- 最多 1 次合理解释

禁止围绕同一个事实连续长出 5 个新利益。

例如原始事实"一颗一泡"：

- 可以：不用每次称茶（合理直接推导）
- 然后停止
- 不要继续自动：所以更省钱 / 更卫生 / 更锁鲜 / 更适合旅行 / 永远不会泡浓（除非这些都在 Sell-point Skill）

---

## 十七、信息增殖检测

如果原始资料只有 10 个事实，最后一篇 300 字文案出现了 25 个产品判断：必须检查。

内部问：多出来的 15 个信息从哪里来的？

Master Copywriting 应该**重组信息**，而不是**繁殖信息**。

---

## 十八、Humanization Pass 3.0

Humanization 阶段明确：**只有表达权限，没有事实权限。**

它可以：删除、换顺序、口语化、增加停顿、调整节奏、改表达方式、增强平台感。

它不能新增：产品事实、人物经历、用户评价、数据、功效、用户结果、市场判断、新适合人群。

---

## 十九、Source Trace Audit（来源追溯审计）

最终生成以后，内部对关键句进行追溯：

| 句子类型 | 问 |
|---|---|
| 产品句 | 来自哪个 Sell-point Fact？ |
| IP 经历句 | 来自哪个 IP Fact？ |
| 用户反馈句 | 来自哪个真实反馈？ |
| 数字 | 来源是什么？ |
| 市场比较 | 数据/事实来源是什么？ |

找不到：删除。

---

## 二十、不要把 Source Trace 输出给用户

正常创作：内部完成。最终用户只看到**自然成品**。

只有用户明确要求"这句话依据是什么？"才展示来源映射。

---

## 二十一、表达自由区

避免 Skill 因为事实约束变得死板。以下不属于新增事实，可以自由发挥：

修辞、比喻、句式、节奏、提问、信息顺序、情绪强弱、镜头语言、画面组织、观点表达、用户代入、CTA 表达。

前提：**不改变事实含义。**

目标不是让文案变保守，而是：**事实边界硬，语言边界宽。**

---

## 二十二、成品验收 5 问

最终每篇检查：

1. **Fact**：有没有一句产品信息超出上游事实？
2. **Person**：有没有一句人物经历没有来源？
3. **Expertise**：有没有把个人标准写成绝对行业定律？
4. **Platform**：是不是这个平台自然会出现的内容？
5. **Conversion**：有没有完成当前内容/种草/卖货目标？

**五项同时成立才通过。**

---

## 二十三、不要因为限制事实导致卖货能力下降

事实约束不是为了让文案犹豫、保守、什么都不敢说。

如果上游事实明确，可以大胆表达：

- Sell-point Skill 明确"第四代传承人制作" → 就可以直接写
- Sell-point 明确"15 泡" → 就可以写 15 泡
- Sell-point 明确"冷泡一夜不苦涩" → 就可以明确写

不要二次弱化。

**原则：已确认事实大胆说，未提供的信息坚决不补。**

---

## 二十四、最终成功标准

| 维度 | 标准 |
|---|---|
| 产品 | 事实能说透，但不会越说越多 |
| IP | 人物有性格，但不会凭空长出人生 |
| 专业 | 有判断，但不会为了权威说绝对话 |
| 卖货 | 敢成交，但不靠夸大 |
| 平台 | 四个平台表达明显不同 |
| 多版本 | 思路不同，但事实边界一致 |

## 与相邻 reference 的边界

- `compliance.md` 管**法律合规**（绝对化用语/功效/数据/稀缺/背书）；本文件管**事实边界**（产品事实/IP 经历/行业定律/竞争克制）。合规是"能不能说"，Expression Authority 是"该不该说、能说到哪"。
- `final-output.md` 管**成品真人感与平台原生层**（信息减法/过度完整/自然连贯/金句限额/平台互换/Humanization Pass 2.0）；本文件把 Humanization 升级为 **3.0**（只有表达权限，没有事实权限），并新增事实扩张测试、IP Fact Firewall、Source Trace Audit。
- `ip-naturalness.md` 管 **IP 内容**（先写人/人格动作/专业表演感）；本文件的 IP Fact Firewall 与 Professional Humility 是其事实边界约束。
- `compliance.md` 的"比较与贬损"与本文件"Competitive Restraint"互补：合规管法律风险，本文件管内容策略。
- `external-intelligence.md` 的 **External Claim Admission Gate** 管**外部信息的表达权限**（Source Type 七分类 / Claim Admission Test / Claim Strength Matching / Claim Cascade Check / Product Transfer Firewall）；本文件管**内部事实的表达权限**（四级权限 / 事实扩张测试 / Expansion Budget / IP Fact Firewall）。两者共同构成完整的 Claim Permission 体系：内部事实有内部事实的边界，外部信息有外部信息的准入。外部信息不得绕过 External Claim Admission Gate 直接进入 Expression Authority 的四级权限体系。
