# Persuasion Integrity（说服力完整性）

> **Source of Truth：G13 说服力完整性判定的唯一来源。** 本文件定义合规修复之后"这篇稿还卖不卖得动"的硬检查。
> **版本**：v4.30.0 新增。
> **类型**：新增商业强度下限约束（不放开 Claim Ceiling、不改 L0-L6、不改 CTA 权限、不改 I5-A 硬禁、不新增暗语/规避手段）。
> **解决问题**：G11/G12 会正确地拦下越线主张，但**修复动作本身没有质量下限**。删掉一个 claim 后如果不补回等强度的主张，成稿会退化为"技术上零违规、实际上没人信"的免责稿——读者读完不知道该买什么、也不相信品牌敢承诺任何东西。合规门只管删得干不干净，不管删完还剩几分购买理由。
> **最高原则**：# Compliance sets the ceiling. Copywriting must fill it.
> 一个被删掉的越线主张，必须在同一位置补上一个**有权限、更直接**的主张。删一个补零 = G13 FAIL。

---

## 一、为什么需要这道门（失败模式溯源）

过度免责不是一种错误，是**五种不同形态的错误**。它们都能通过 G1-G12，然后在 G12 之后静默落地：

| 编号 | 失败模式 | 机制 | 读者实际收到的信息 |
|---|---|---|---|
| F1 | **Hedge Laundering（免责洗白）** | 越线主张被"合法化"成一个合规但不可验证的近似句 | "它在说自己有这个东西，又好像不太确定" |
| F2 | **Burden Shift（举证责任外推）** | 把验证动作推给读者（"你自己去查""对着备案表看"） | "品牌自己都说不清，要我自己去核对" |
| F3 | **Disclaimer Reformat（免责换皮）** | 免责声明不是删掉，而是改写成"伪事实句"留在正文 | "它花了很大篇幅告诉我它不干什么" |
| F4 | **Deletion Without Replacement（只删不补）** | 越线段落直接删掉，附近没有补任何主张 | "这段广告在回避什么" |
| F5 | **Confidence Collapse（确信度塌陷）** | 全篇主张被降级成条件句、反问句、间接引语 | "这个品牌什么都不敢承诺" |

F1-F5 有一个共同点：**它们都是合规安全的**。所以现有 G1-G12 无法判 FAIL——判不了不是因为规则缺失，是因为规则只定义了"不能写什么"，没有定义"删完之后必须剩下什么"。

## 二、G13 五项硬检查

全部为**可判定项**。逐项执行，命中即 REPAIR；F5 严重塌陷时升级 BLOCK。

### G13.1 — Burden Shift Prohibition（禁止举证责任外推）

**禁止**在正文中把验证产品的动作交给读者。判据：句子的主语如果是"你"且谓语是核查行为，或出现指向读者自行验证的祈使结构 → FAIL。

禁止句式（示例，非穷举）：

- "备案平台上能查到" / "你可以自己去搜"
- "备案成分表上写得清清楚楚，你可以自己对着看"
- "不信的话自己去查"
- "这个我没法说，你只能自己去确认"
- "具体以官方页面为准"（当它承担了本该由品牌承担的证明责任时）

**为什么禁**：这类句子在合规上零成本，在说服上是负分。它把品牌该负的举证责任转嫁给读者，而读者几乎不会真的去查——他只会得出"这品牌自己都说不清"的结论。**举证责任永远属于表达方，不属于接收方。**

**修复方向**：不是删掉，是**替读者把结论说完**。同样的事实由品牌自己下判断：

- 改前："备案编号 2025002192，备案平台上能查到。"
- 改后："备案编号 2025002192。这是普通化妆品能做的是保湿和舒缓，别的它不碰。"

前者要读者自己去查才知道这产品是什么，后者直接告诉读者它是什么、边界在哪。**边界讲清楚 ≠ 免责。** 明确说清"不做什么"是可信度资产；把"不做什么"包装成免责腔才是负债。

### G13.2 — Proof Substitution（删一个必须补一个）

**规则**：G11/G12 每删除或降级一条越线主张，必须在同一叙事位置补入一条**权限不低于 L2、表达强度不低于原句**的主张。

- 允许的补法：换成 L1 属性事实、L2 授权主张、L3 证据主张、L4 用户价值翻译。
- 不允许的补法：换成"具体以官方页面为准"、换成参数罗列、换成情绪但无主张的空话、留一段纯场景描写。
- **只删不补 = FAIL。** 段落长度不变但主张密度下降，等于把销售理由蒸发掉。

**删前的自检**：删之前先在事实账本里找好替换句。找不到替换句，说明这个 claim 当初就不该写——问题在 Draft，不在 G 审核。

### G13.3 — Assertive Claim Floor（直陈主张下限）

每篇 Sell / 引流稿必须满足的**数量下限**（按平台、字数折算）：

| 平台 | 正文长度 | 直陈主张句下限 |
|---|---|---|
| 抖音口播 / 千川 | ≤ 200 字 | ≥ 2 |
| 抖音口播 / 千川 | > 200 字 | ≥ 3 |
| 小红书 | 任意 | ≥ 3 |
| 公众号 / 长文 | 任意 | ≥ 4 |

**直陈主张句**定义：主语是产品或用户可见的具体对象，谓语是产品动作或状态，陈述强度为肯定式，且**不含** hedge 标记。

**Hedge 标记**（出现在主张句中即不计入）：可能 / 也许 / 或许 / 大概 / 听说 / 据说 / 好像 / 似乎 / 应该是 / 相对 / 一定程度上 / 有点 / 个人觉得 / 因人而异 / 视情况 / 建议 / 建议尝试 / 一般来说 / 通常。

注意：hedge 标记可以用在**非主张句**里（口播的过渡、语气词、场景描写），但每有一处，必须有一句无 hedge 的直陈主张与之平衡。

**Seed 稿**下限为 Sell 的一半——种草建立偏好，也需要一句明确的价值判断。

### G13.4 — No Disclaimer Content（免责声明不得入正文）

与 `commercial-expression-freedom.md` 二十五节的既有规则一致，本 Gate 提供**可执行判据**，把"禁止"变成可机械检查的清单：

正文出现以下任一结构 → FAIL：

1. 自我能力否定："它不负责……" / "它做不到……" / "别指望它……" / "我不指望它……"
2. 免责后缀："效果因人而异" / "仅供参考" / "并非医疗作用"（法律强制要求展示的除外）
3. 法规解释："按法规普通食品不能宣传功效" / "所以我们不能说它能……"
4. 说教插入："买之前先学会看这一行字" / "那些话术听听就好" / "我劝你……"

**唯一例外**：法律、法规、平台规则强制要求展示的警示语与必要声明。这类内容不进正文口播，单独按要求展示。

### G13.5 — Confidence Restoration Pass（确信度恢复遍）

**顺序强制**：G11/G12 修复完成后、H2 去 AI 打散之前，必须执行一遍**只加不减**的确信度恢复。

执行规则：

- 这一遍**只允许增强、不允许删除或弱化任何主张**（任何削弱动作一律回退到 G 审核阶段处理）。
- 逐条检查被 G11/G12 标记过的位置：那一段现在的主张句够不够直接。
- 典型修法：
  - 条件句还原成直陈句（"如果你也是泛红干燥的人，它适合你"→"它就是给泛红干燥的皮肤用的"）
  - 被动改主动（"成分表上写着 X"→"它加了 X"）
  - 去掉无意义的间接引语（"我觉得它可能还不错"→"它还不错"）
  - 把"用户可能注意不到"改成"它有一个不容易被发现的好处"
- 这一遍**不得新增事实、数字、来源**（同 H1/H2 纪律）。

## 三、Confidence Recovery（越线主张的正确替换顺序）

当一个最想讲的主张被 G11/G12 拦下，**按此顺序**处理，不得跳步：

```
1. 降主张层级（不删内容）——L6 → L4 用户价值翻译
2. 换证明载体（不降表达）——用 L1/L2/L3 事实支撑同一结论
3. 换场景落点（保情绪强度）——把功效落点改成使用场景、感官、决策成本
4. 才允许删除（且必须已通过 G13.2 补位）
```

**绝对禁止的跳步**：

- ❌ 直接删除（跳过 1-3）→ F4 只删不补
- ❌ 换成免责句（"具体的以官方为准"）→ F2/F3
- ❌ 换成合规但同义的近似句 → F1 Hedge Laundering

F1 的识别方法：把改前改后两句放在一起，问"**一个只读改后句子的用户，会得出和读改前一样的结论吗？**"

- 会 → 不是洗白，是正常替换
- 不会（改后句的信息量或确定度明显更低）→ 是洗白，FAIL

## 四、示例（对照改法）

### 示例 1 — F2 Burden Shift

- ❌ 改前："有十四天和二十八天的人体功效评价，走的是正规评价流程。"
- ❌ 改后（错）："它有 14 天和 28 天的人体功效评价报告，你可以自己去看。"
- ✅ 改后（对）："28 天人体功效评价做过了。它的效果不是嘴上说的，是有人一批一批用了一个月记下来的。"

### 示例 2 — F1 Hedge Laundering

- ❌ 改前："它有专利的 PDRN 透皮吸收技术。"
- ❌ 改后（错，透皮吸收不可信）："它有透皮吸收相关的研究支持。"
- ✅ 改后（对，落到可验证的原料事实 + 直接表达）："它的核心成分 DNA 钠，在国家药监局公布的已使用化妆品原料目录里，序号 383。这东西不是概念，是有编号的原料。"

### 示例 3 — F4 只删不补

- ❌ 改前（原稿 8 秒）："备案编号 2025002192，十四天二十八天人体功效报告。"
- ❌ 改后（错）：删掉整段，只留前后句子。
- ✅ 改后（对）：同一位置换成用户可感的决策信息——"价格不到两百，脸上出问题的时候你不会先去查备案编号，你会先想这支能不能每天用。"

### 示例 4 — G13.3 直陈主张补位

- ❌ 改后（错，全篇 hedge）："它的效果可能因人而异，不过整体来说成分还不错。"
- ✅ 改后（对）："它就是给干皮、泛红、上妆卡粉准备的。成分表短，敏感期也能顶一阵。"

## 五、与相邻 Gate 的边界

| Gate | 管什么 | 与 G13 的区别 |
|---|---|---|
| G11 Semantic Claim Audit | 这句话能不能说（法律与语义边界） | G11 说"不许说"，G13 说"删完之后必须补上什么" |
| G12 Review Risk Audit | 平台与投放风险 | G12 管平台过审，G13 管过审之后还卖不卖得动 |
| G1-G5 | 事实为不为真 | G1-G5 保证不编造，G13 保证不编造的同时**说得出话** |
| H2 去 AI 打散 | 结构匀速、套路感 | H2 打散之后必须重新过 G13——打散可能把直陈句拆成碎句，顺手削掉主张密度 |
| `commercial-expression-freedom.md` 二十五节 | 边界是内部标准（原则层） | 该文件是原则，G13.4 是可机械检查的清单 |
| `claim-authority.md` L0-L6 | 主张表达权限（能说什么） | G13.2 只在**已有权限范围内**要求补位，不放宽权限、不新增权限 |
| `compliance.md` | 法律合规底线 | 合规说"不能写"，G13 说"不能写成空稿" |

**G13 永远不放宽 Claim Ceiling。** 补位主张必须本来就有权限（L1-L5）。任何"为了 G13 而多说一句"导致越线的，改动回退到 G 审核，由 G11/G12 判定——**不允许 G13 成为绕过合规的通道**。

## 六、执行位置

```
Route → minimal bundle → Draft（含 5.3 段落作用拆解）
  → H1 口语校准
  → G1-G12 full review / repair（G11/G12 删除或降级主张，逐条记录被处理的位置）
  → **G13 说服力完整性（G13.5 确信度恢复遍 → G13.1/2/3/4 逐项判定）**
  → H2 de-AI 打散
  → **G13 复核（只查 H2 是否削掉主张密度，不重复全检）**
  → read-only invariant check → sanitizer → deliver
```

H2 之后必须复核的原因：去 AI 打散会把匀速长句拆成短句，拆分过程中最容易顺手丢掉主句的谓语，留下只剩主语和状语的残句——句式自然了，主张没了。

---

## 七、最终最高原则

> # 删掉违规主张，不等于删掉购买理由。
> # 合规修的是话，不是销售的意愿。
> # 每一处删减，都必须留下一个更有权限、更直接的说法。
> # 敢把边界讲清楚的品牌，比处处免责的品牌更容易被相信。
